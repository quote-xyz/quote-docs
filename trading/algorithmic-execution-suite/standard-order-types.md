# Standard Order Types

Besides professional execution, Quote provides a standard suite of order types:

* Market orders
* Limit orders
* Scale orders
* Standard TWAP orders

For applicable order types, a privacy option can be enabled to protect trading strategies from frontrunning. More information on Standard Order Types can be found on the [Hyperliquid Documentation](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/order-types).
